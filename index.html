Como jogar

Use as setas / WASD (ou os botões abaixo no celular) para mover o BobRoll pelo labirinto.

Colete todos os pontos evitando o Nó, o Emperro, a Poeira e o Atraso.

Pegue o Turbo (polietileno grande) para virar o jogo e derrotar os rivais!
